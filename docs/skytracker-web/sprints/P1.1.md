# Sprint P1.1 – Global Live Map

## Scope

P1.1 removes the fixed regional viewport limitation without changing the
production chain:

```text
Browser
→ OpenLura same-origin API
→ Cloud Run
→ Firestore Budget Gate
→ OpenSky
```

Motion, Replay, Historical Track, selection, details, favorites and filters
remain on their existing paths.

## Global query policy

Every finite MapLibre center is mapped to a deterministic 4° × 4° query
window. Windows use an overlapping 2° grid so small pans keep the same cache
key. At the poles and antimeridian the window shifts inward and never sends
cross-antimeridian bounds unsupported by the backend.

This policy:

- works for every world longitude and latitude;
- always stays at 16 square degrees;
- creates stable, reusable backend cache keys;
- requests only the region around the current map center;
- does not attempt an unsafe whole-world provider query at low zoom.

## Region transitions

Map movement is debounced. Crossing into a new query window schedules the
latest region immediately when possible, with a minimum 30-second interval
between client requests. Repeated movement inside one window is deduplicated.
If several moves happen while a request is active, the obsolete request is
aborted and only the latest region remains relevant.

The previous accepted snapshot is retained while the new region loads. Empty
successful snapshots are applied and shown as an honest, subtle empty-region
status.

## Budget and scale

- Normal refresh remains six minutes.
- A single browser session is capped at 240 request starts per rolling day,
  below the backend limit of 300 provider operations.
- Successful normalized region responses are shared for five minutes in the
  Vercel CDN; browser storage remains `no-store` and errors are not cached.
- Fixed query windows improve cache and coalescing reuse between visitors.
- The Firestore Budget Gate remains the authoritative global hard stop.
- Motion never schedules network activity.

The 300-operation anonymous OpenSky budget still limits total public scale.
P1.1 makes navigation bounded and cache-friendly; it does not claim that the
anonymous allowance provides unlimited worldwide concurrency.

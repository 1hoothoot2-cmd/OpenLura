# SkyTracker Web Account Strategy

Accounts zijn optioneel. De Live Map blijft zonder account bruikbaar.

Toekomstige accountfunctionaliteit:

- synchronisatie van favorites;
- gebruikersvoorkeuren;
- alerts;
- premiumrechten;
- veilige cross-device sync.

Supabase wordt uitsluitend gebruikt voor gebruikers- en accountdata. Supabase
is geen live-aircraftprovider, motionbron, viewportbackend of historische
trackprovider.

Anonieme gebruikers krijgen geen verborgen account of verplichte onboarding.
Accountfunctionaliteit vereist een afzonderlijke privacy-, security-,
retentie- en lifecyclebeslissing.
